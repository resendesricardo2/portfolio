## 🛠️ Stack Tecnológica & Arquitetura

### **Frontend & Interface**
- **Vue 3 (Composition API):** Reatividade modular, gestão limpa de componentes e separação de responsabilidades.
- **Vite:** Bundler ultra-rápido para compilação local e otimização de ativos em produção.
- **CSS3 Avançado:** Glassmorphism, animações fluidas, CSS Variables para temas e layout 100% responsivo (Mobile First).

---

## ✨ Funcionalidades em Destaque

- 🔍 **Filtragem Inteligente de Projetos:** Pesquisa em tempo real por nome e stack tecnológica (Vue, Python, Flask, PostgreSQL).
- ⚡ **Filtro de Estado (Live vs. Offline):** Separação clara entre projetos em produção e projetos locais.
- 🖼️ **Galeria Modal de Capturas de Ecrã:** Pop-up interativo para explorar imagens de projetos locais/offline sem sair da página.
- 💼 **Timeline de Experiência e Formação:** Apresentação cronológica da carreira técnica e percurso escolar.
- 📬 **Integração de Contacto Direto:** Atalhos diretos para Email, LinkedIn, WhatsApp e GitHub.

## 💻 Como Executar Localmente

Se pretenderes testar a aplicação no teu ambiente local:

1. **Clona o repositório:**
   ```bash
   git clone [https://github.com/resendesricardo2/portfolio.git](https://github.com/resendesricardo2/portfolio.git)
   ```

2. **Instala as dependências:**
   ```bash
   npm install
   ```

3. **Inicia o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Gera a compilação para produção:**
   ```bash
   npm run build
   ```
